# iFSI

iFSI is a supporting module for the [FEBioMFEMiFSI](https://github.com/JolleyLab/FEBioMFEMiFSI) project. It provides specialized functionality for immersed fluid-structure interaction (FSI) modeling using the [MFEM](https://github.com/mfem/mfem) finite element library.

Important: iFSI is not a standalone application; it is designed to work exclusively as part of the FEBioMFEMiFSI framework.
