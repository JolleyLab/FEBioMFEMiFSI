# MFEMFSI

MFEMFSI is a supporting module for the FEBioMFEMiFSI project. It provides specialized functionality for immersed fluid-structure interaction (FSI) modeling using the MFEM finite element library.

Important: MFEMFSI is not a standalone application; it is designed to work exclusively as part of the FEBioMFEMiFSI framework.
